十五键笔画打字练习 · 全屏离线

装到 iPhone 桌面

两种方式，任选一种
A

系统描述文件（带图标，一步装好） 点蓝色按钮 → 允许下载 → 打开「设置 → 通用 → VPN 与设备管理」→ 点「十五键笔画练习」→ 安装 → 桌面出现蓝色图标，点开即全屏练习。

① 下载桌面图标配置
B

Safari 手动添加（不用装配置） 点灰色按钮打开练习 → Safari 底部分享按钮 → 添加到主屏幕 → 命名「十五键」→ 添加。效果一样，图标由系统生成。

② 直接打开练习
永久可用：练习页托管在 GitHub Pages（HTTPS），装好后不依赖 Minis、不依赖本地服务，关掉 App 也能打开；题库已内嵌，断网照常练。
图标随时可长按删除，不改动手机任何设置。
